# Architecture

## A. Video analysis path

1. A video frame is passed through YOLOv8 for vehicle detection.
2. Detection centres are checked against a configurable region-of-interest polygon.
3. In-ROI detections contribute to class-weighted demand. This signal is a proxy generated by the detector, not ground-truth traffic density.
4. DeepSORT associates detections across frames and supports traffic analytics.
5. The density-prediction component maintains a rolling history, constructs summary/trend features and forecasts 15 frames ahead after its training warm-up.
6. The dashboard exposes the live pipeline state and diagnostic forecast information.

## B. Intersection-control path

The multi-approach controller receives demand information for the N/E/S/W approaches and combines current demand with an optional prediction contribution. The conflict-safe phase controller represents opposing movements through NS/EW phases with yellow and all-red clearance intervals. A four-approach allocation vector should not be mistaken for permission to display conflicting greens simultaneously; the signal-state layer is responsible for conflict-safe phase transitions.

The dashboard's single-video quadrant-split mode is a UI/demo convenience. It does not provide the equivalent of four independent, synchronized camera feeds and must not be reported as a real four-camera experiment.

## C. Evaluation paths are separate

### Video predictor evaluation

`scripts/capture_rf_eval.py` runs the detector/pipeline over one input clip and matches each 15-frame forecast to the pipeline's detector-derived weighted density at the target frame. It also computes an EMA comparison. No future frames are used to form a forecast, but the evaluation targets are produced by the same detector pipeline rather than independent manual labels.

### SUMO controller evaluation

The SUMO scripts run a synthetic four-arm microscopic network. The baseline comparison contrasts fixed-time, Webster and reactive controllers. The predictive ablations use per-approach halting counts returned by SUMO to update a separate predictor per approach. These experiments isolate aspects of the control policy; they do not run YOLO video through SUMO.

In the video path, the RF horizon is measured in frames (15 frames ≈ 0.25–0.30 seconds for the clips examined). In the SUMO path, each step is one simulated second, so the 15-step forecast horizon is 15 simulated seconds. These units must remain distinct in results and the paper.
